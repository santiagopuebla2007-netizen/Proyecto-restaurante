GUARDIA VIEJA RESTO BAR
Documentación del proyecto de diseño
============================================================

1. DESCRIPCIÓN
------------------------------------------------------------
Proyecto de diseño de una web para Guardia Vieja Resto Bar,
presentado como un restaurante de Vistalba, Luján de Cuyo,
Mendoza, Argentina.

La propuesta permite conocer el restaurante, consultar su carta
gastronómica y visualizar un recorrido de reserva de mesas.
También incluye pantallas de acceso y gestión administrativa.


2. OBJETIVO
------------------------------------------------------------
Comunicar la identidad cálida, íntima y rústica del restaurante,
facilitar la consulta de comidas y bebidas y presentar un flujo
de reservas acompañado de una vista de administración.

3. CONTENIDO Y PANTALLAS
------------------------------------------------------------
INICIO
- Presentación de Guardia Vieja Resto Bar.
- Navegación hacia Menú, Local, Quiénes somos, Contacto,
  Ubicación y Mis reservas.
- Llamada a la acción para reservar.

MENÚ GASTRONÓMICO
- Introducción a la propuesta gastronómica.
- Selección de principales, postres y bebidas.
- Pantallas de platos con imágenes y descripciones.
- Controles visuales para avanzar, retroceder y volver al menú.

BEBIDAS
- Gaseosas y limonada.
- Bebidas alcohólicas y cócteles, entre ellos vermut, fernet,
  Aperol, ron, gin tonic, Campari, tequila y daiquiri.
- Cervezas Andes Origen.
- Vinos tintos
- Vinos blancos

LOCAL Y QUIÉNES SOMOS
- Presentación del ambiente del restaurante.
- Relato de sus orígenes y su identidad gastronómica.
- Contenido orientado a encuentros, aniversarios y cenas.

CONTACTO Y UBICACIÓN
- Pantalla de contacto con referencias a Instagram y WhatsApp.
- Acceso a Ubicación desde la navegación principal.
- Los destinos reales de estos accesos no se verificaron.

RESERVAS
- Formulario visual con fecha, hora, cantidad de personas,
  nombre y apellido.
- Botón Reservar.
- Pantalla de confirmación con el mensaje «¡RESERVA EXITOSA!».
- Acceso «Mis reservas» en la pantalla de inicio; no se
  identificó una vista específica para consultar reservas propias.

ADMINISTRACIÓN
- Pantalla de acceso con usuario y contraseña.
- Estado visual de error por credenciales incorrectas.
- Vista «Reservas de hoy» con cliente, contacto, fecha/hora,
  personas y acciones.
- Controles visuales para eliminar una reserva y limpiar la lista.
- Los registros mostrados deben tratarse como contenido de
  ejemplo del diseño, no como reservas reales verificadas.

4. IDENTIDAD VISUAL
------------------------------------------------------------
- La portada utiliza un fondo verde oscuro, textos claros
  y detalles de tono oliva.
- El nombre del restaurante tiene protagonismo tipográfico,
  con una presentación de estilo serif.
- La navegación y los textos secundarios emplean una estética
  más discreta.
- La propuesta se apoya en fotografías de gastronomía y local.
- Las pantallas principales están diseñadas en formato de
  escritorio de 1440 x 1024.
